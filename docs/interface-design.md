# Dirección de interfaz

La interfaz es un espacio de entrenamiento de inglés para una persona que necesita saber qué practicar, cuánto dura y qué ha aprendido realmente. No es una página de venta.

## Sistema visual

- Fondo niebla `#F3F6FA`, superficie `#FFFFFF`, tinta `#192D47`, azul de acción `#2457BC`, azul suave `#E8EFFB`, acento de fluidez `#BCE5DF`.
- Public Sans para instrucciones y navegación; Georgia para los títulos de estudio; Commit Mono solo para cronómetros. Se reutilizan las fuentes disponibles, sin nuevas descargas.
- Contenido alineado a la izquierda. Inicio con dos rutas de entrenamiento de diferente carácter, seguido del ejercicio breve y del acceso al progreso. En móvil, una sola columna sin elementos flotantes que tapen controles.

```text
Marca             Prácticas / Progreso           Perfil
Saludo y propósito                  Resumen real
Práctica A integral       Práctica B fluidez
Gimnasia temporal         Cómo se consolida el aprendizaje
```

## Revisión del concepto

Se descarta el mosaico de tarjetas equivalentes porque oculta la diferencia entre una sesión completa y un bloque breve. No se muestran porcentajes inventados, rachas ficticias ni promesas de dominio por una sola revisión. Los colores distinguen rutas, pero siempre se acompañan de nombres y duraciones.

La preparación de llamada conserva la elección explícita del tutor y del idioma. El bloque temporal tiene una llamada de escucha y transcripción, texto de solo lectura, cuatro pasos y cierre explícito con «Terminé este paso». El reloj no corta la voz. Una sola revisión escrita al cerrar cada captura; ninguna respuesta conversacional durante las pausas. Se conservan los límites y el guardado de ensayos sin certificar dominio. El contraste, el foco de teclado, el tema oscuro y el flujo móvil forman parte del diseño.

Skill utilizada: `anthropics/skills`, `frontend-design`, instalada en `.agents/skills/frontend-design`. Se conserva su licencia. No es una dependencia de producción.
